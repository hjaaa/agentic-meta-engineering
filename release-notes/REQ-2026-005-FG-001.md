# FG-001 · audit log warning-only 列变化

## 概述

本次变更（REQ-2026-005 FG-001）调整了 4 个 Gate plugin 的 `_legacy_to_report` 行为，
并为 `GATE-REVIEWS-CONSISTENCY` 新增了 CI 全量扫描路径。

## audit log warning-only 列变化

**变更前（旧行为）**：
- 当 Gate 仅产生 WARNING（无 ERROR）时，`_legacy_to_report` 返回 `Decision.PASS`
- 这些 Gate 在 audit log 中渲染为 **PASS（绿色）**
- 即使在 `--strict` 模式下，`audit.calc_exit_code` 的 `has_warning_fail` 也不会被触发（因为 decision=PASS）

**变更后（新行为）**：
- 当 Gate 仅产生 WARNING（无 ERROR）时，`_legacy_to_report` 返回 `Decision.FAIL`，code=`R-WARNING-ONLY`
- 这些 Gate 在 strict 模式下的 audit log 中渲染为 **FAIL（红色）**，exit=1
- **非 strict 模式不变**：Gate severity=warning，`calc_exit_code` 仅在 `strict=True` 时把 `has_warning_fail` 升级为 exit=1

## 影响范围

### 涉及的 4 个 plugin

1. **GATE-META-SCHEMA** (`scripts/gates/plugins/meta_schema.py`)
   - 纯 warning 时从 PASS → FAIL（code=`R-WARNING-ONLY`）

2. **GATE-SOURCING** (`scripts/gates/plugins/sourcing.py`)
   - 纯 warning 时从 PASS → FAIL（code=`R-WARNING-ONLY`）

3. **GATE-PLAN-FRESHNESS** (`scripts/gates/plugins/plan_freshness.py`)
   - W001/W002/W003 纯 warning 时从 PASS → FAIL（code=`R-WARNING-ONLY`）

4. **GATE-INDEX-INTEGRITY** (`scripts/gates/plugins/index_integrity.py`)
   - 纯 warning 时从 PASS → FAIL（code=`R-WARNING-ONLY`）

### 新错误码

`R-WARNING-ONLY`：表示该 Gate 仅产生 warning 级 finding，无 error 级 finding。
- 仅在 strict 模式下导致 exit=1（非 strict 不变）
- 报告中包含首条 warning 的文件/code/message，以及所有 warning 的完整列表（`vars.warnings`）

## GATE-REVIEWS-CONSISTENCY CI 兜底

FG-001 同时为 `GATE-REVIEWS-CONSISTENCY` 新增了 CI 全量扫描支持：

- **registry.yaml**：`triggers` 新增 `ci`
- **CI 路径逻辑**：扫描所有 `requirements/*/meta.yaml`，对每个 `reviews.<phase>.latest` 字段
  确认 `requirements/<id>/reviews/<latest>.json` 文件存在
- 不一致时返回 `Decision.FAIL`，code=`R-REVIEWS-INCONSISTENT`

## 向后兼容性

- 非 strict 模式行为不变：exit=0（即使存在纯 warning 的 Gate fail）
- 已有 error 级 Gate 失败的行为不变
- `R-WARNING-ONLY` 仅在 strict 模式下导致 CI 拦截
