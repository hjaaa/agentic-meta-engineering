# asd-plan-lite — 显式降级通道

默认走 Superpowers 全流程保质量;本 skill 是唯一合法的轻量出口——先裁决,后降级,
不允许跳过裁决直接开写。

## 三问裁决(任一问答"是"即不得降级,回到完整流程)

1. 是否跨多个模块/系统边界?(是 → 上下文丢失成本高)
2. 是否改 schema、状态机、或产生外部副作用?(是 → 返工代价高)
3. 是否存在"出错后无法靠常规测试轻易发现"的后果?(是 → 需要更强验证)

把三问结论(各一行)呈现给用户确认后再继续。

## 三问全"否"时的轻量路径

1. 不写 spec,不建 asd/specs/ 文件;向用户口头确认一句话范围与完成判据。
2. 直接实现,仍守两条底线:TDD(测试先行)+ 原子提交。
3. 完成声明前仍要证据:跑受影响的测试并贴输出(琐碎改动可豁免整条 pipeline,
   但不豁免"跑过才算数")。
4. 途中发现触碰三问任何一条(范围长大了),立即停下升级为完整流程。
