# asd-learn — 知识沉淀

知识条目只收"事实"(隐式依赖、历史坑点、领域约束——模型猜不出、猜错代价大的);
"规矩"(编码规范、命名约定、禁止操作)不进 knowledge/,提示用户写进 CLAUDE.md。

## 步骤

1. 与用户确认三件事:事实内容(一句话说清)、触发关键词(3-5 个,含同义写法)、来源(哪次需求/事故)。
2. 写 `asd/knowledge/<kebab-slug>.md`,一条事实一个文件:

   ```markdown
   # <标题>

   关键词: <a, b, c>(loader.sh 按此行与正文做大小写不敏感匹配)

   <事实本体,1-3 段>

   **为什么**: <不遵守会发生什么;来源事故/需求>
   **怎么应用**: <设计/实现时的具体动作>
   ```

3. 在 `asd/knowledge/index.md` 追加一行 `- [标题](文件名) — 关键词: a, b, c`。
4. 已有条目覆盖同一事实时更新原文件,不建重复条目;发现条目过时就地修正或删除。
