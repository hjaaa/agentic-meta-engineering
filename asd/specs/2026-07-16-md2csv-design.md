# md2csv — Markdown 表格转 CSV 脚本设计

> ASD-INJECTION: active

## 目标

提供一个零依赖的 Python 3 小脚本,把 markdown 文件中的 GFM 管道表格转成 CSV。

## 用法

```
python3 md2csv.py [input.md] [-o PREFIX]
```

- 有文件参数时读文件,无参数时读 stdin。
- 输出路由:
  - 单表格 + 无 `-o` → 写 stdout(支持管道组合)。
  - 给了 `-o PREFIX`:单表格 → `PREFIX.csv`;多表格 → `PREFIX-1.csv`、`PREFIX-2.csv`…(按出现顺序编号,从 1 开始)。
  - 多表格 + 无 `-o` → 默认前缀:输入文件名去扩展名(如 `report.md` → `report-1.csv`);stdin 模式用 `table` 作前缀。

## 表格识别与单元格处理

- 只识别标准 GFM 管道表格:表头行 + `|---|---|` 分隔行 + 若干数据行;没有分隔行的 `|` 行块不算表格。
- 分隔行本身不输出。
- 行首/行尾竖线可有可无,两种写法都支持。
- 单元格内容:去首尾空白;`\|` 反转义为 `|`;其余行内标记(加粗、斜体、`` `代码` ``、链接等)原样保留。
- CSV 编码与转义全部交给标准库 `csv` 模块(逗号、引号、换行均正确处理)。

## 错误处理

- 输入中找不到任何表格:向 stderr 输出提示,退出码 1。
- 数据行列数与表头不一致:照原样写出(csv 模块支持不等长行),不报错、不补齐——保守处理,不猜测用户意图。
- 输入文件不存在:向 stderr 输出提示,退出码 1。

## 结构

- 单文件 `scripts/md2csv.py`(约 80-100 行):
  - `extract_tables(text) -> list[list[list[str]]]`:纯函数,输入 markdown 文本,返回表格列表(每个表格是行列表,每行是单元格列表),便于独立测试。
  - `main()`:参数解析与 IO 路由。
- 测试 `scripts/test_md2csv.py`,标准库 `unittest`,用 `python3 -m unittest` 运行。

## 测试覆盖

- 基本表格(表头 + 分隔行 + 数据行)。
- `\|` 转义单元格。
- 含逗号、引号的单元格(验证 CSV 转义)。
- 多表格拆分与编号。
- 无表格输入(退出码 1)。
- 有/无首尾竖线两种表格写法。
- 列数不齐的行照原样输出。

## 明确不做(YAGNI)

- 不识别代码块围栏:```` ``` ```` 内的伪表格也会被转出。若日后输入常含代码块,再加围栏跳过逻辑(约 10 行)。
- 不剥离单元格内的行内格式。
- 不支持 HTML 表格、缩进式表格等非 GFM 管道语法。
