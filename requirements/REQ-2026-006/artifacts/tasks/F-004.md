# F-004 · PR-4 异步 audit + run.py main BaseException 兜底 + audit_flush.py + audit-flush.sh + SessionEnd hook 条目

## 需求描述

fail-open 兜底 + 审计与决策解耦失败域 PR——可与 F-003 并行（改 run.py 不同段落）。

具体动作：
- **`scripts/gates/run.py` 改动**（detail-design §4.1）：
  - (a) 把现有 `main()` 函数体重命名为 `_real_main()`，新建 `main()` 作为 try/except 包装：拦截非 SystemExit 的 BaseException 写 `/tmp/run-py-error.log` 后 `return 2`
- **`scripts/gates/audit.py` 改动**（detail-design §4.2）：
  - (b) `write_audit()` 改为通过 subprocess 调 `scripts/lib/audit_async.sh::audit_append_async`（best-effort，失败静默；entry 名 hard-code `'runner'`，引入 `shlex.quote` 防注入——见 detail-design 评审 R2 修订）
- **新增 `scripts/lib/audit_flush.py`**（detail-design §4.3）：
  - 读 `audit/.queue/*.log` 解析按 entry 分桶
  - 写 `audit/<YYYY-MM>/<entry>-<YYYY-MM-DD>.json`（注意：是 entry-日期，不是 trigger-ts；同日多次 flush 走 append，不去重不覆盖）
  - mv 已处理 `.log` 到 `audit/.queue.done/<YYYY-MM-DD>/`（不删，便于审计回滚；同名文件改名 `<原名>.dup<N>.log`）
- **新增 `.claude/hooks/audit-flush.sh`** 薄壳调用 `audit_flush.py`（detail-design §4.4）
- **修 `.claude/settings.json`**：SessionEnd hooks 新增 `audit-flush.sh` 条目，与 `extract-experience.sh` 并列（detail-design §4.5）
- **新增测试**：`tests/gates/test_audit_async.py` + `tests/lib/test_audit_flush.py` 覆盖故障注入

## 接口/数据结构

冻结接口（detail-design §4.1 / §4.3 / §7）：

```python
# scripts/gates/run.py
def _real_main(argv: list[str] | None = None) -> int:
    """原 main() 函数体，逻辑不变。"""
    ...

def main(argv: list[str] | None = None) -> int:
    """新顶层包装：拦截非 SystemExit 的 BaseException → 写 /tmp/run-py-error.log → return 2。"""
    try:
        return _real_main(argv)
    except SystemExit:
        raise
    except BaseException:
        # log to /tmp/run-py-error.log, return 2 (trigger 层 fail-open)
        ...
        return 2
```

```python
# scripts/lib/audit_flush.py
def main(argv: list[str] | None = None) -> int:
    """入口；返回 0 永不抛异常。
    
    支持 --dry-run 仅打印计划不动文件。
    """
    ...
```

audit_flush 输出文件命名（detail-design §4.3，覆盖 outline-design 初稿）：
- `audit/<YYYY-MM>/<entry>-<YYYY-MM-DD>.json`（按日期一桶；entry ∈ runner / submit / trigger:submit / pre-tool-use-guard / ...）
- archive：`audit/.queue.done/<YYYY-MM-DD>/<原名>.log`，同名时 `<原名>.dup<N>.log`

> 评审 -002 minor 提醒：`_parse_lines` 解析策略建议用 `rsplit(" @ entry=", 1)` 兼容 event 段含 JSON dump 的场景（PR-4 实施时落地）。
