# F-001 · PR-1 新增 pre-tool-use-guard.sh + bats + audit_async.sh + settings.json 切换 + spec 注释同步

## 需求描述

热路径解耦的核心 PR——把 PreToolUse hook 链路从 1875 行 god-object 替换成 ~60 行 bash 单文件。

具体动作：
- 新增 `.claude/hooks/pre-tool-use-guard.sh`（3 条规则 + `trap 'exit 0' ERR` + audit 留痕；shebang 用 `#!/usr/bin/env bash` 统一 macOS/CI bash 解析路径，detail-design §1.1）
- 新增 `scripts/lib/audit_async.sh` 含 `audit_append_async` / `audit_flush_queue` 两函数 + `ENTRY_*` 常量（detail-design §1.3）
- 新增 `tests/hooks/test_pre_tool_use_guard.bats` 24 用例（V-01 7 类场景 + 12 种写入 pattern + ≥2 反例 + V-06 hyperfine）
- 修改 `.claude/settings.json` PreToolUse 一行切到新 guard（detail-design §1.4）
- 修改 `.github/workflows/quality-check.yml` 加 bats-core / hyperfine 安装 step（detail-design §1.5）
- 顺手修 `context/team/engineering-spec/design-guidance/gate-system-architecture.md:153` 的 jq 注释（接受 fail-open，不实现 python3 fallback，detail-design §1.6）

新旧并行：旧 `protect-branch.sh` 不删，settings.json 切走即等同失活；PR-1 验证 1-2 天后才合 PR-2。

## 接口/数据结构

冻结接口（detail-design §1.1 / §1.3 / §7）：

| 模块 | 函数 / 入口 | 输入 | 输出 | 副作用 |
|---|---|---|---|---|
| `pre-tool-use-guard.sh` | `main()` | stdin JSON | exit 0/2 | 写 `audit/.queue/<日期>.log` / `/tmp/guard-error.log` |
| `audit_async.sh` | `audit_append_async <line> [entry]` | 行字符串 / 入口名（默认 ENTRY_RUNNER） | - | append `audit/.queue/<日期>.log` |
| `audit_async.sh` | `audit_flush_queue` | - | - | 调 `audit_flush.py`（PR-4 落地，本 PR 占位） |
