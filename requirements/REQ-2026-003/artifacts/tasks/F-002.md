# F-002 · routing.py tty 卡点 + 4 档热键 + audit + 写盘

## 需求描述

在 F-001 核心层基础上**叠加 IO 层**：tty 校验 + 4 档热键交互（D-002）+ audit 写入 + 原子写盘 + main() 主入口（含 trivial-skip 短路 + 异常→退码映射）。完成后通过 5 条 pty 集成测试（T1-T6）+ 2 条单测（U11-U12）。

> 派发提示：本 feature 一次性打包了 7 项 IO 内容（v1 评审 minor 4），实施时若上下文紧张可考虑拆 F-002a（tty + prompt + audit）/ F-002b（write_scope + main + 错误映射），契约边界在 RoutingPlan / RoutingDecision dataclass 已固定，可串行无返工。

## 接口/数据结构

详见 `requirements/REQ-2026-003/artifacts/detailed-design.md`：

- §2.3 `main()` 入口：8 步流程（parse → check_tty → load_yaml → validate_schema → enumerate_diff → build_plan → 分支[trivial-skip / prompt_user] → write_scope）
- §2.4 IO 函数签名：`_check_tty` / `_prompt_user` / `_resolve_confirmed_by` / `_write_scope` / `_audit_log`
- §6 错误文案模板 `_ERROR_MESSAGES: dict[int, str]`（5 退码各一段，含 fix-hint）
- §8.1 输入解析规则表（"" / "a"|"A" / "q"|"Q" / 数字逗号 / invalid）
- §8.2 数字逗号子集解析 + must 强制保留逻辑
- §8.3 连续无效 3 次阈值（MAX_INVALID_PROMPTS=3）
- §8.4 audit 颗粒度（accept/all 不写，custom 写 [code-review-route-custom]，q/3 次无效 各写 [code-review-aborted]，trivial 写 [code-review-skipped]）
- §3.1 完整 scope JSON 字段（_write_scope 输出契约）
- §3.2 不变量 I1-I8（写盘前断言）

**关键不变量**：

```
I1: decision="trivial-skipped" ⇔ skipped=true ∧ checker_route=[] ∧ skipped_checkers 含 8 个
I2: decision="all" ⇔ skipped=false ∧ checker_route == ALL_CHECKERS
I3: decision="custom" → checker_route 必含 plan 中所有 must 命中 checker
I5: routing_decision.tty_verified 必须 true
I8: len(checker_route) + len(skipped_checkers) == 8（除 trivial-skip 外）
```

## 验收

详见 `features.json` F-002.acceptance：

1. **T1-T5 pty 集成全过**：
   - T1: 直接 enter → decision=accept
   - T2: `a\n` → decision=all，checker_route == ALL_CHECKERS
   - T3: `1,3\n` → decision=custom，must 项强制保留校验
   - T4: `q\n` → 退码 5 + audit `[code-review-aborted] 用户主动取消 (q)`

2. **T6 非 tty stdin（pipe）→ 退码 2**，stderr 文案匹配 §6 模板
3. **U11-U12 容错全过**：
   - U11: `"1, 3"` / `" 1 ,3 "` / `"1,3 ,5"` 解析正确
   - U12: 用户输 `"2"` 去掉 must 1 后最终 final_route 仍含 must 1（must 强制保留）
4. **trivial-only diff 路径**：不读 stdin、不展示推荐集，写 skipped=true 后退码 0 + audit `[code-review-skipped] N 文件全在 trivial 白名单内（routing-auto）`
5. `_write_scope` 出口 .review-scope.json 满足 §3.2 I1-I8 八条不变量
