# F-001 · review-schema 升级 + save_review CR 规则扩展 + 旧 verdict 处置基础

## 需求描述

为后续所有 feature 提供契约基础——升级 verdict schema 至三档机器评估 + human_signoff 子 schema，扩展 save_review.py 的 CR 规则（新增 CR-7 / CR-8，平移 CR-1/2/3/4/6 到新枚举），实现旧 verdict 干跑迁移脚本骨架。

本 feature 不动 reviewer Agent 输出空间（在 F-003 改）；不动下游门禁判定（在 F-004b 改）。

## 接口 / 数据结构

详见 `requirements/REQ-2026-003/artifacts/detailed-design.md`：
- §F-001.2 review-schema.yaml 精确变更（含 schema diff 写法清单 + 4 项操作明细）
- §F-001.3 save_review.py CR 规则签名（CR-7 / CR-8 与既有 _check_cr_rules 同构 + CR-1/2/3/4/6 平移表）
- §F-001.4 migrate_review_v2.py 干跑脚本接口（scan / render_dry_run_report / apply_rename）

- ⚠️ CR-1 / CR-4 改读 `is_signed_off` helper——但该 helper 在 F-004b 才实现。本 feature 实施时先 import 占位（如果 F-004b 未合并，import 失败时 CR-1/4 跳过），通过 try/except ImportError 兜底；F-004b 合并后自动启用
