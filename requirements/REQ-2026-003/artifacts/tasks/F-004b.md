## 实施注意

- ⚠️ `is_signed_off` 实现严守一份语义——所有调用方（GATE-REVIEW-VERDICT / feature-lifecycle-manager）走同一段 Python（在 wrapper 内 inline 或直接 import）。**禁止**调用方各自 grep / 字符串解析
- ⚠️ `scripts/check-signoff.sh` 必须用单引号 heredoc 形式包 Python（详见 §F-004.4 wrapper 示例），不可用双引号包 `python3 -c`，否则 zsh / bash 引号嵌套踩坑
- ⚠️ ai-collaboration.md 规则三要禁止三种调用形态：`/code-review:signoff` / `bash scripts/save-review.sh signoff` / `python3 scripts/lib/save_review.py signoff`——三层都要列
- ⚠️ cutover 清单的"已 completed/abandoned 不处理"与"GATE 逐次切阶段触发"的张力消解段（§F-004.6 末段）必须原文写入 spec 文档，避免后续维护者扯皮
- ⚠️ AI 代签 3 层防御手工冒烟（验收第 7 条）必须真跑——在子 Agent shell 调三种形态，全部退出码 2 才通过
