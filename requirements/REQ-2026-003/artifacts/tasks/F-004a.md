## 实施注意

- ⚠️ Command 层 < 100 行硬上限（command-spec.md），仅做预检（4 条）+ 委托 Skill；写盘动作必须落到 Skill / save_review.py
- ⚠️ Skill 二次 tty 校验是**深防御**，禁止以"过度工程"为由删除——成本 < 10ms，收益是阻断管道注入与绕过 Command 直调
- ⚠️ argparse 升级时**必须**保证 `python3 save_review.py --req X --phase Y --reviewer Z`（无 cmd）走 save 路径，与既有 `save-review.sh` 零改造兼容；TC 必须覆盖此回归
- ⚠️ `--source` CLI 参数当前枚举仅 `cli-tty`，仍要保留为 CLI 参数（预留 D-004 未来扩展，避免未来再改 CLI 形态）
- ⚠️ process.txt append 必须在 save_review.py 内调 `requirement-progress-logger` 同款逻辑（取 now 时间戳 + 单行格式 `[signoff] <REV-ID> <decision> by <email>`），不要预算时间戳
