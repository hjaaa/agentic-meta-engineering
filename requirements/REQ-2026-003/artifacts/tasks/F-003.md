# F-003 · Judge 三档收敛 + report 模板更新

## 需求描述

把 `code-quality-reviewer` Agent 的 conclusion 取值从旧三档（approved / needs_revision / rejected）替换为新三档（looks_clean / needs_attention / blocked）；明文禁止 AI 输出 `approved` 或写入 `human_signoff` 字段。同步更新 `code-review-report` 模板加「路由说明」段（输出卡点 A 的确认信息）+「待 sign-off 提示」段（指引开发者执行 /code-review:signoff）。

## 接口 / 数据结构

详见 `requirements/REQ-2026-003/artifacts/detailed-design.md`：
- §F-003.2 .claude/agents/code-quality-reviewer.md 替换段（L199-205 三档结论规则重写 + 明文禁止清单）
- §F-003.3 code-review-report 渲染段增量（路由说明段 + 待 sign-off 提示段；含 mustache-style 模板片段）
