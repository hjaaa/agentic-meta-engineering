# F-002 · check_reviews.py 与 save_review.py 退化签字判定

## 范围

- `scripts/lib/check_reviews.py`
- `scripts/lib/save_review.py`
- 对应测试 `tests/lib/test_check_reviews.py` / `tests/lib/test_save_review.py`

## 实施步骤

1. `check_reviews.py`：删 `SIGNOFF_PASS` 常量与 `is_signed_off` 函数；R003 分支只判 `conclusion ∉ {blocked, rejected}`；R007 分支只判 done feature 有 latest code review 且 conclusion 不为 blocked/rejected（来源：spec:124）
2. `save_review.py`：删 CR-1 / CR-4 中对 `is_signed_off` 的依赖；删 CR-8 整条规则；删 argparse `signoff` 子命令 parser 分支与对外 re-export（来源：spec:125 + spec:120）
3. 测试同步：`test_check_reviews.py` 删 signoff 相关 case；新增"缺 human_signoff 字段的 latest review 通过 R003"用例；新增"done feature looks_clean 时 R007 通过；blocked 时 R007 失败"用例（来源：spec:148-152）
4. `test_save_review.py` 删 CR-8 测试；保留收紧 CR：required_fixes 非空 + looks_clean 失败；score < 70 + looks_clean 失败（来源：spec:154-156）

## 验收

- `rg 'is_signed_off|SIGNOFF_PASS' scripts/lib/check_reviews.py scripts/lib/save_review.py` 0 命中
- `save_review.py --help` 子命令列表不含 `signoff`
- `pytest tests/lib/test_check_reviews.py tests/lib/test_save_review.py -q` 全过
