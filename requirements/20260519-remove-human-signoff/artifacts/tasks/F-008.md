# F-008 · 迁移当前 review JSON 删除 human_signoff 字段

## 范围

仓库内当前活跃 / testing 中需求的 `requirements/*/reviews/*.json`；不动已 archived completed 需求。

## 实施步骤

1. 列出活跃需求：从 `requirements/*/meta.yaml` 读 phase；非 `completed` 视为活跃
2. 写一次性 Python 脚本（不入仓，按 AC-A1 决议）：
   - 读 reviews/*.json
   - 若 含 `human_signoff` 字段，删除该键
   - in-place 重写 JSON（保留 key 顺序 + indent=2）
3. 跑 `git diff requirements/<active>/reviews/` 验证仅 `human_signoff` key 被删
4. commit message 显式列出被改的需求 ID 与文件数

## 验收

- 迁移后 `git diff requirements/<active>/reviews/` 仅显示 human_signoff key 删除
- `rg 'human_signoff' requirements/<active>/reviews/` 0 命中
- 已 archived completed 需求 `requirements/<archived>/reviews/*.json` 仍含 human_signoff（hash 不变）
- commit message 列出 active 需求 ID 列表（如 `20260519-remove-human-signoff`）
