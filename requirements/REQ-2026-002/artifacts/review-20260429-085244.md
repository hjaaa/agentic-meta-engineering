## Major（强烈建议修复 / round-2 must_fix）

### [design-consistency · F-1] scripts/gates/run.py:448

`force-with-blockers` 代码接受 `phase-transition` + `submit` 两个 trigger，但 `registry.yaml:316` spec 限定 `triggers=[submit]`，行为越权 spec。

**建议**：二选一收口——A) 把 `phase-transition` 加进 `registry.yaml` escape_hatches.triggers；B) 代码限回单一 `submit`。同步补单元测试覆盖越权用例。

### [design-consistency · F-2] scripts/gates/registry.yaml:314-318

`force-with-blockers` 未列 `skips_gates` / `skips_gates_with_tag`，run.py:447-487 实现是「全 trigger 范围跳过」；spec §1 未明确流程级 vs gate 级覆盖语义。

**建议**：detail-design §1 加注释「force-with-blockers 是流程级 escape_hatch，跨所有 submit-trigger gate 强制覆盖；与 legacy-requirement 的 gate 级 skips_gates_with_tag 区分」。

### [design-consistency + security · F-4] scripts/gates/run.py:468 + audit.py:70

audit 写 `escape_reason` 字段，但 detail-design §2.3 audit schema 字段表只列 `escape_used` 未列 `escape_reason`；同时 reason 无长度上限（恶意 reason 写 100KB 仍接受）。

**建议**：spec §2.3 字段表补 `escape_reason` 语义；run.py:367-375 reason 校验补 `max_len=1024` 字符 + 控制字符过滤。

### [complexity · F-7] scripts/gates/run.py:410-487

`_execute_plan` AST 实测 **78 行 / CC≈14**（5 个 try/except 分支 + force_used 状态机 + audit_extra 拼装），超 60 行 / CC 10 项目硬阈。

**建议**：拆 `_handle_escape_hatch`（处理 force-with-blockers 路径）+ `_build_audit_extra`（拼装 escape_used/escape_reason）；目标主函数 ≤ 50 行 / CC ≤ 10。

### [error-handling · F-8] scripts/gates/migration/render-docs.py:125

`_load_registry` 仅捕 `Path.exists` 缺失，未捕 `yaml.YAMLError` + `OSError`；CI `render --check` 路径下 registry.yaml 损坏会冒泡为进程 exit 2，而非门禁 fail。

**建议**：`try yaml.safe_load except (yaml.YAMLError, OSError) as exc:` 打 ERROR 日志后 `sys.exit(1)`，让 CI 显示为门禁失败而非脚本崩溃。

### [auxiliary-spec + design-consistency · F-11+F-13 合并] requirements/REQ-2026-002/artifacts/features.json + .claude/skills/

F-004 acceptance#3「git grep 无残留引用」与 description「删 lib/check_*.py」双重未达：
- `scripts/lib/check_*.py` 5 个文件全在（plugins 仍 import）
- `.claude/skills/` 4+ 处旧入口残留：`feature-lifecycle-manager/SKILL.md:46-58` / `reference/subagent-dispatch.md:99` / `reference/feature-states.md:9` / `requirement-doc-writer/SKILL.md:19` / `reference/sourcing-rules.md:55-57` / `managing-requirement-lifecycle/SKILL.md:15`
- features.json description 与 modules 字段自相矛盾

**建议**：二选一——A) 改 description+modules 与现状对齐（lib/*.py 长期保留，标记「plugins import 依赖」），并清理 `.claude/skills/` 4+ 处残留（推荐）；B) 真删 lib/*.py（须先迁移 plugins import 路径，工作量大）。
