## Critical（必须修复）

### [error-handling/design-consistency] scripts/gates/triggers/pre_tool_use.sh:73 (F-001)

Hook 阻断协议错误：`exit $?` 透传 run.py 退出码——run.py:578-582 `_calc_exit_code` 在 has_error_fail 时 `return 1`。Claude Code PreToolUse Hook 协议 exit 1 是 non-blocking error，**exit 2 才阻断 tool 调用**；H5 核心防御能力实际失效，所有 Bash 写 reviews/*.json 拦截退化为仅 stderr 提示而无实际阻断。

**建议**：
```bash
python3 scripts/gates/run.py --trigger=pre-tool-use
rc=$?
[ $rc -eq 0 ] && exit 0 || exit 2
```

### [concurrency/error-handling] scripts/gates/run.py:443-456 (F-002)

`commit_staged_writes` 抛异常时落入 `generic except Exception` 分支，**不调用各 plugin 的 rollback 也不 clear ctx.staged_writes**（clear 仅在 GateFailed 分支 line 442），仅 `_restore_state` 恢复磁盘备份后 `return 2`；事务化承诺虚设——partial-commit 状态会持久化到内存对象（同进程复用 ctx 时累积），plugin 自身的 rollback 钩子失效。

**建议**：commit 循环抛异常时显式 `raise GateFailed(...)` 复用现有 rollback 路径；或在 `except Exception` 分支补 `for g in reversed(executed): g.rollback(ctx)` + `ctx.staged_writes.clear()`。

### [security] scripts/gates/plugins/bash_write_protect.py:108-112 + scripts/gates/run.py:524-545 (F-008)

### [concurrency] scripts/gates/plugins/review_verdict.py:341-350 (F-010)

**建议**：落盘前 `fcntl.lockf` 锁 meta.yaml 全过程，或落盘前重新 load 仅 merge 改动字段。

**建议**：改 GH-CALL-FAILED 为 `Decision.PASS`（降级仍打 WARNING）或 registry severity=warning；删除 fix_hint 中不存在的 `--skip` 说法或补 escape_hatch。

### [performance] scripts/gates/triggers/pre_tool_use.sh:33-63 (F-017)

**建议**：合并为单次 `python3 -c` 输出 NUL/换行分隔三字段，shell IFS 拆分；改动 ~10 行无新依赖。

### [performance] scripts/gates/run.py:97-119,161-215 (F-018)

**建议**：`load_registry` 增 `validate_only_ids` 参数，filter 先于 S2；或开发态轻量 load 模式仅校验 YAML schema。
