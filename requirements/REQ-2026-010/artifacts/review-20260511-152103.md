### [error-handling/logging-level-missing-error] scripts/lib/workflow_run.py:596

`except BootstrapError as exc` 后仅 `print(f"ERROR: bootstrap 失败：{exc}", file=sys.stderr)`，未 `logging.error`；CLAUDE.md §3.1 要求不可恢复异常用 ERROR 级，且 _bootstrap_rollback 内部各步已用 logging.error，主路径反而缺失，前后不一致。

**建议**（rev2）：在 print 之前加 `logging.error("bootstrap req_id=%s 失败，已触发 rollback：%s", req_id, exc)`。

### [error-handling/silent-swallow-nonzero-returncode] scripts/lib/workflow_run.py:478, 499

`_bootstrap_rollback` 内两处 `subprocess.run([...], check=False)`：
- L478 `git checkout previous_branch` 失败（如分支被删 / detached HEAD）returncode != 0 完全静默
- L499 `git branch -D feat/req-<id>` 失败（分支不存在 / 权限）returncode != 0 完全静默

rollback best-effort 不重抛是正确的，但**不等于可以无日志静默**。当前 except 只能捕 SubprocessError/OSError；rc != 0 不抛异常时完全无线索。

**建议**（rev2）：两处 subprocess.run 后立即判：

```python
if result.returncode != 0:
    logging.error(
        "rollback req_id=%s step=%s rc=%d stderr=%s",
        req_id, "git_checkout", result.returncode, result.stderr.strip(),
    )
```

`stderr` 已通过 capture_output 落地，加 log 零额外开销。
