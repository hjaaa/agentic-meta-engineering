# F-007 · approval 节点 + main loop break（方案 ii）

## 需求描述

_dispatch_approval_node 写 approval_pending 事件后立即返回 DispatchResult(outcome='approval_pending')；main loop 见此 outcome 时设置 state=approval_pending 并 break。用户敲 /workflow:approve 后由 /workflow:continue 续跑。

## 接口/数据结构

详见 `artifacts/detailed-design.md` §5.1 / §5.2。约束：
- approval_pending 事件包含当前 node_id + 提示语
- main loop 见 approval_pending → 写 RunState.state = approval_pending + break
- /workflow:continue 从下游节点恢复（依赖 RunState.rebuild）
