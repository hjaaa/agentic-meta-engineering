# F-011 · loop / sub_workflow 节点最小实现（深度联动留后续）

## 需求描述

_dispatch_loop_node：根据 run_state.loop_counters 写 loop_iteration_started/completed，达到 max_iterations 后返回 loop_done。_dispatch_sub_workflow_node：派子 run 到 run_dir/sub_runs/<node_id>/，返回 sub_workflow_pending（等 main loop break，下次 continue 时检测子 run 状态）。

## 接口/数据结构

详见 `artifacts/detailed-design.md` §5.1。约束：
- loop_counters 在 RunState.rebuild 时正确累计（关联 F-005 RunState 扩展）
- sub_workflow 子 run 物理位置 = `run_dir/sub_runs/<node_id>/`
- "深度联动"（多级嵌套 + 子 run 完成后回填）留下一个 REQ
