# F-002 · _bootstrap_requirement + _bootstrap_rollback

## 需求描述

完成需求类 bootstrap 副作用三步：建 requirements/<id>/artifacts/ + 写 meta.yaml/plan.md/process.txt + git checkout -b feat/req-<id> + jsonl workflow_started。任一步失败触发 _bootstrap_rollback 反向撤销（branch -D + rmtree），不吞掉原始异常。

## 接口/数据结构

详见 `artifacts/detailed-design.md` _bootstrap_requirement / _bootstrap_rollback 段。关键约束：
- bootstrap 步骤按时序追加 done_steps，rollback 时倒序撤销
- raise 原始异常前必须先尝试 rollback；rollback 自身 IOError 不抛出
- jsonl workflow_started 事件在所有副作用完成后才写
