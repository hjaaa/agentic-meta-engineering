# F-008 · main loop 替换 stub + 失败处理矩阵

## 需求描述

workflow_continue.py 的 _main_loop_stub 替换为真正的 while 循环；按 outcome 路由（completed → next；loop_continue → 保持 current_node；approval_pending/sub_workflow_pending → break；failed → _handle_failure 按 on_failure retry/skip/abort 分支）。

## 接口/数据结构

详见 `artifacts/detailed-design.md` §5.2（main loop 状态机 + _handle_failure 矩阵）。
关键路由表：
| outcome | 处理 |
|---|---|
| completed | 进入下一个拓扑节点 |
| failed | _handle_failure(retry / skip / abort) |
| approval_pending | RunState.state=approval_pending, break |
| loop_continue | current_node 不变，loop_counter+1 重派 |
| loop_done | 跳出 loop 节点，进入下一个 |
| sub_workflow_pending | 子 run 已派，break 等下次 continue |
| skipped | 等同 completed 但写 node_skipped |

- on_failure=skip：失败节点写 node_skipped，main loop 继续
- on_failure=abort：state=failed 后 break；下次 continue 拒绝续跑
