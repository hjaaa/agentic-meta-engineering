## 建议（非阻断 follow-up）

- **F-003-S1 [minor · test-correctness]** `test_glob_match_simple_star`（`:238-244`）的注释比断言更值得保留——它点出了 `fnmatch.fnmatch` 的 `*` **会跨 `/`** 这个反直觉行为（`assert glob_match("context/sub/foo.md", "context/*.md") is True`，`:242`）。这条断言是当前 `glob_match` 实现的"真实行为"，但与多数读者对 glob 的直觉相反。**建议**：在 `markdown_links.py:268` 的 `if "**" not in pattern: return fnmatch.fnmatch(...)` 上方加一行注释 `# 注意：fnmatch 的 * 跨 / 匹配，与 git/zsh glob 语义不同；带 ** 的分支才走"段内 *"语义`。不影响 F-003 关闭，属于源码侧文档债。

- **F-003-S2 [minor · test-completeness]** `test_extract_links_code_block_pseudolink_skipped`（`:87-92`）只覆盖 fenced ``` 内的伪链接被跳过，未覆盖 inline `` ` `` 内的 `[fake](fake.md)`。从 `mask_code_blocks` 实现（`markdown_links.py:84` 的 `_RE_INLINE_CODE.sub`）看，inline code 内的 `[](...)` 也应被 mask，但当前 `_RE_INLINE_CODE = re.compile(r"`+[^`\n]+?`+")` 不允许 `` ` `` 内含换行，且 `[link](url)` 序列里有 `]` 和 `(`、`)` 但无 `` ` ``，所以 `` `[fake](fake.md)` `` 整段被 mask 后 LINK_RE 不会命中。**建议**：补一条用例 `extract_links("see \`[fake](fake.md)\` here") == []` 以锁死这条不变量；防止未来有人改 `_RE_INLINE_CODE` 时引入回归。不阻断 F-003。

- **F-003-S3 [minor · style]** 文件头注释（`:1-11`）写了"覆盖 7 个公开 API"，但 import 段（`:22-31`）实际还引入了 `MarkdownLink`（NamedTuple，非函数）。`MarkdownLink` 也是公开 API（`__all__` 风格暴露的类型），但被归在"链接提取"语义下。**建议**：把头注释改成"覆盖 7 个公开函数 + MarkdownLink 数据结构"，或者直接说 "8 个公开符号"。不阻断，文档准确性微调。

## 跨维度洞察

- **测试用例的"显式注释 ↔ 行为契约"双向锚定**很到位。如 `test_resolve_link_nonexistent_file_returns_path_not_none`（`:163-168`）的 docstring 直接复述了 `markdown_links.py:163` 的"目标不存在时仍返回理论路径，断链由调用方判定"约定。这种"测试当作可执行规范"的写法，未来如果有人误把 resolve_link 改成"不存在就 return None"，测试会立刻红，且失败信息能指回设计意图。建议在 `context/team/engineering-spec/` 的测试规范里把这条记为推荐模式。

- **mask_code_blocks 的长度不变性是隐性契约**，`test_mask_code_blocks_length_preserved_with_trailing_newline`（`:308-312`）和 `test_mask_code_blocks_inline_code_replaced`（`:283-291` 的 `assert len(masked) == len(md)`）已经把这个不变量锁死了。这是 F-001 review 里点出的"masked 行号必须与原文一一对应"的兜底——如果 `mask_code_blocks` 哪天因优化（比如改成丢弃整段 fenced 内容）破坏了长度等长，`extract_links` 里 `orig_m = LINK_RE.search(orig_line, m.start())`（`markdown_links.py:115`）的 `m.start()` 偏移会立刻失效，行号全错。这一对测试是整个 markdown 解析栈的护栏，价值远超字面覆盖率。

- **测试与待测目标的 path 强耦合是当前 layout 的小代价**。`sys.path.insert(0, str(Path(__file__).resolve().parents[2] / "scripts" / "lib"))`（`:20`）这种手动 path 注入是因为 `scripts/lib/` 不在标准 `src/` 布局中。其他测试（如 `tests/gates/test_index_integrity_plugin.py`）也走同样模式，所以一致性是 ok 的；但如果项目后续引入 `pyproject.toml` 的 `tool.pytest.ini_options.pythonpath`，这一行就能删。不影响 F-003 关闭。
