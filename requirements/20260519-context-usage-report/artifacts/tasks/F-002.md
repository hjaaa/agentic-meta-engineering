## 验收标准

- check_index.py 不再包含 **常量 / 正则 / 复杂业务逻辑**（具体清单：LINK_RE / _is_external_or_intra_anchor / _slugify 三项必须删除）
- 保留 `_extract_links` / `_extract_headings` / `_resolve_link` 三个 **Path → 文本的 IO 适配函数体** 是可接受的——它们：
  - 仅做 `read_text(encoding="utf-8")` + 调 markdown_links 同名公开函数，无重复实现
  - `_resolve_link` 含 1 处 fallback（markdown_links.resolve_link 返回 None 时按"相对 INDEX 目录 / 绝对仓库根"构造路径），属 check_index 局部边界处理，不污染 markdown_links 公共 API
  - 总计 ≤ 21 行 body，无 regex / 常量定义
- tests/gates/test_index_integrity_plugin.py 全绿（pytest 无新增失败用例）
- index-config.yaml 的 ignore 语义未受影响（手动跑 python3 scripts/lib/check_index.py 输出与切换前对比 diff 为空）

> **2026-05-20 AC 修订记录**：原 AC-1 字面"不再包含 _extract_links / _resolve_link / _extract_headings 函数体"过严，与 markdown_links 模块"纯文本接口"的设计取舍冲突——markdown_links 不读 Path 是为了让其纯函数式可复用。check_index.py 保留 IO 适配 wrapper 是合理的层次分离。本次 traceability-gate 校验暴露后修订 AC 文本，让"不再包含"精确化为"不再包含常量/正则/复杂业务逻辑"。详见 notes.md 同日 F-002 AC 修订段。
