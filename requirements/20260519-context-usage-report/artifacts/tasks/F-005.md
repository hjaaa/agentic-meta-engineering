## 验收标准

- IndexGraphResult.indexed_by 键为文件 rel_path，值为 INDEX 路径列表（按字典序）
- broken_links: 给一个 fixture INDEX 列了不存在的文件，能在结果中识别且带 index_path:line + target
- orphans: 给一个 fixture 文件存在但 INDEX 未引用，能识别
- 外链（http://...）与 intra-anchor（#foo）跳过，不计入 indexed_by
