## Major issues（3 条，1 必修 / 1 必修 / 1 follow-up）

### M1 · warnings 全链路缺 stderr 输出 + WARN 前缀【必修】

- **位置**：`scripts/lib/context_usage_report.py:1591-1594`（_print_summary）+ `:1577`（warnings.append）
- **现象**：
  - `_print_summary` 仅 `print(f"Warnings: {len(warnings)}")` 到 stdout（数量计数）
  - warnings 内容从不打到 stderr，CI grep `WARN` 完全失效
  - `warnings.append` 消息也未带 `WARN ` 前缀
- **设计要求**：`detailed-design.md:781-782`「用 print to stderr 输出 warning / error 行」+「行格式 `<LEVEL> <message>`」+ 示例 `WARN reviews/foo.json: json.loads failed`
- **修复**：`_print_summary` 增补 `for w in warnings: print(f"WARN {w}", file=sys.stderr)`

### M2 · format=both 时 md/json 写入无事务性【必修】

- **位置**：`scripts/lib/context_usage_report.py:1601-1606`（_render_and_write）
- **现象**：md 成功 + json 写失败 → 旧 md 已覆盖、json 不一致（半写状态）
- **设计**：L764「保留写错误 → exit 5」未明示半写是否可接受
- **修复（建议组合）**：(A) 前置 `render_markdown` + `render_json` 得到两份 content 后再批量 write，缩小窗口；(C) 在 stderr 提示用户哪一份写成功
