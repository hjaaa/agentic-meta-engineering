## Major（强烈建议修复）

### [error_handling] scripts/lib/workflow_dispatcher.py:443-469

`_dispatch_loop_node` 的 subprocess.run 仅捕 TimeoutExpired，未捕 OSError（bash 不在 PATH / cwd 不存在等场景）。同文件 `_dispatch_bash_node:323-338` 是对称基线，明确同时 catch TimeoutExpired + OSError；本处缺 OSError 分支属对称性破损，bash 不在 PATH 时 FileNotFoundError 会逃逸到入口。

**建议**：在 `except subprocess.TimeoutExpired` 后追加一段
```python
except OSError as exc:
    _write_loop_iteration_with_error(jsonl_path, node_id, current_iteration, f"oserror: {exc}")
    return _loop_check_max_or_continue(node_id, current_iteration, max_iterations, jsonl_path)
```
`oserror:` 前缀与 `timeout:` 对齐，使 `data.error` 在不同失败类型间保持可 grep 一致。
