# F-006 · approval 闭环（approve + reject inline repair + attempts）

> 来源：`requirements/REQ-2026-011/artifacts/features.json` · `F-006`
> 设计：`requirements/REQ-2026-011/artifacts/detailed-design.md`（按 ac_refs 检索）
> priority=P0 · ac_refs=AC-03 · pr_group=P0 · estimate_days=4.0

## 需求描述

scripts/lib/workflow_approve.py 在 isatty + state 校验通过后，用 append_events 原子写 [approval_approved, node_completed]（AC-03a）。scripts/lib/workflow_reject.py 引入 DEFAULT_APPROVAL_MAX_ATTEMPTS=3（D-009），反扫 jsonl 统计 prior_rejects 得 current_attempt，yaml on_reject.max_attempts override；attempt<max → 用 append_events_with_manifest 原子写 [approval_rejected, approval_repair_started]（**batch ≥4KB 时触发 manifest fallback，单字段 ≥3500 入选外置**，v6 P2 二段语义；reason 单字段超 3.5KB 但 batch 仍 <4KB 时直写不外置）；attempt==max → 原子写 [approval_rejected, node_failed(reason=approval_attempts_exhausted), workflow_failed]。落地 ADR D-007 + D-009 + AC-03a/b/c。
