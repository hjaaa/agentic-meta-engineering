## 需求描述

新建 scripts/lib/save_node_result.py（D-001 独立模块），CLI: --run --node --kind={skill_result|approval_repair} --output --attempt。**fail-closed 复合三件套（对抗审阅 P1-1 v6 修订）**：(1) state != awaiting_claude_action → exit 2 (E-NODE-RESULT-001)；(2) `_check_node_match_or_fail` 节点身份校验——skill_result 要求 run_state.current_node == --node ∧ jsonl 末位 awaiting 事件 = node_ready(node)；approval_repair 要求 run_state.pending_approval == --node ∧ jsonl 末位 = approval_repair_started(node)；任一不匹配 → exit 2 (E-NODE-RESULT-002/003/004)；(3) approval_repair 时 --attempt 必填且与 started.attempt 一致 → 否则 exit 1。--kind=skill_result → 写 node_completed；--kind=approval_repair → 写 approval_repair_completed。output 走 append_events_with_manifest 由其 batch ≥4KB + 单字段 ≥3500 二段触发算法决定 manifest fallback。__不__抽公共 helper 与 save_review.py 共用（D-012）。确认 .claude/hooks/pre-tool-use-guard.sh 拦截列表不含 save_node_result.py（PR description 注明，R-I01 mitigation）。落地 ADR D-001 + D-012 + AC-04a/b。
