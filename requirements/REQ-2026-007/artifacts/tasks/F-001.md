# F-001 · 门禁放宽 B 案 + run.py --draft 透传

## 需求描述

B 案 plugin 内自处理（D-013）。

- 改 `scripts/gates/plugins/ahead_of_origin.py`：precheck 加 `_detect_source_branch` + `_pr_open_for_branch` 谓词，命中即 Skip（detail-design §3.2.1）；fail-closed 策略：gh 缺失/401 → 不 skip 走主路径
- 改 `scripts/gates/plugins/review_verdict.py`：precheck 顶部加 submit + `--draft` → Skip（§3.2.2）
- 改 `scripts/gates/run.py`：parse_args 紧跟 `--target` 加 `--draft`（§1.5 #9）
- 改 `scripts/gates/triggers/submit.py`：argparse 加 `--draft` + 写入 `ctx.cli_flags['draft']`（§3.2.3）
- 新增 `tests/gates/test_ahead_of_origin.py` 加 V-02 用例 + `tests/gates/test_review_verdict.py` 加 V-03 用例

**实施纪律**：先抓 §2.3 回归基线（V-06）再改代码，改完跑 diff 对比；新增 skip 是预期，新增 fail 必须排查。

## 接口/数据结构

- `_detect_source_branch(ctx) -> str`：从 ctx 取当前分支
- `_pr_open_for_branch(branch: str) -> bool`：调 `gh pr list --head <branch> --state=open --json number`；返回非空 → True；FileNotFoundError / returncode∈{1,4,7} → 抛上层走 fail-closed
- `ctx.cli_flags: dict[str, Any]`：submit trigger 写入 `{'draft': bool}`
- `--draft` flag 仅在 trigger=submit 生效；其他 trigger 透传但不影响
