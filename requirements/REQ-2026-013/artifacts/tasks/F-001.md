# F-001 · check_reviews.py R005 hash 比对 normalize（A2 路径）

> 来源：`requirements/REQ-2026-013/artifacts/features.json` · `F-001`
> 设计：`requirements/REQ-2026-013/artifacts/detailed-design.md` §3.1 + §4.1
> ADR 依据：D-001（A2 改 R005 校验放宽）/ D-007（normalize 白名单 = {status, updated_at}）

## 需求描述

scripts/lib/check_reviews.py 的 R005 hash 比对在遇到 `artifacts/tasks/*.md` 时，把 dev 期演进字段（status / updated_at）从 frontmatter strip 掉再算 sha256；其他 artifact 走整文件 hash 旧路径保兼容。修完不破坏现有 ~13 个 completed 需求 verdict.artifact_hashes（A2 双侧 normalize 设计意图）。

## 触及范围

- scripts/lib/check_reviews.py
- tests/lib/test_check_reviews_normalize.py（新增）
- tests/lib/test_check_reviews_normalize_schema_sync.py（新增）

## 实施步骤

1. 在 check_reviews.py import 区下加 `_NORMALIZE_TASK_FIELDS: set[str] = {"status", "updated_at"}` 常量。
2. 新增 `_strip_frontmatter_fields(content: str, fields: set[str]) -> str` 模块级函数（详见 detailed-design §3.1）。
3. 新增 `_compute_hash_with_normalize(file_path: Path, path_str: str) -> str` 模块级函数。
4. 改造 `_r005_hash_drift` line 285-289 的 hash 计算行，用 `_compute_hash_with_normalize(file_path, path_str)` 替代 `hashlib.sha256(f.read()).hexdigest()`。
5. 新建 tests/lib/test_check_reviews_normalize.py，覆盖 4 类基础用例 + 性能基准 + 兼容性参数化（详见 detailed-design §4.1）。
6. 新建 tests/lib/test_check_reviews_normalize_schema_sync.py，校验 `_NORMALIZE_TASK_FIELDS ⊆ schema.required_fields`。
7. 跑 `pytest tests/lib/test_check_reviews_normalize.py tests/lib/test_check_reviews_normalize_schema_sync.py -v` 全过。
8. 跑 `python3 scripts/gates/run.py --trigger=ci --strict` 全仓扫确认无新增 R005。

## 验收

- scripts/lib/check_reviews.py 含 `_NORMALIZE_TASK_FIELDS` 常量 + 2 个新函数
- `_r005_hash_drift` 函数 hash 计算行改用 `_compute_hash_with_normalize`
- pytest 2 个新文件全过
- 性能基准：1000 次 normalize hash 路径相对整文件 hash 路径 overhead < 5%
- 现有 completed 需求跑 ci gate 后 R005 无新增
