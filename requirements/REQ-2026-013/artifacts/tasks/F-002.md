# F-002 · touches_guard.py out-of-repo 短路（cwd-driven）

> 来源：`requirements/REQ-2026-013/artifacts/features.json` · `F-002`
> 设计：`requirements/REQ-2026-013/artifacts/detailed-design.md` §3.2 + §4.2 + §4.6
> ADR 依据：D-006（cwd-driven `git rev-parse --show-toplevel`）/ D-011（双源并存 + 各自语义文档化）

## 需求描述

修复 touches_guard.py PreToolUse hook 在主 Agent 写仓库外路径（/tmp / /var / ~/）时误记 violation 的问题。引入 cwd-driven `git rev-parse --show-toplevel` 派生仓库根，与既有 file-driven `_REPO_ROOT`（保留给 `_is_in_touches`）双源并存，各自语义清晰，worktree edge case 不冲突。

## 触及范围

- .claude/hooks/touches_guard.py
- tests/hooks/test_touches_guard_out_of_repo.bats（新增）

## 实施步骤

1. 在 touches_guard.py 顶部模块 docstring 加 D-011 双源声明段（详见 detailed-design §3.2.1）。
2. 新增 `_get_worktree_toplevel() -> Optional[Path]` 函数：subprocess 调 `git rev-parse --show-toplevel`，超时 2s，异常 / returncode != 0 返回 None。
3. 新增 `_is_out_of_repo(file_path: str, toplevel: Optional[Path]) -> bool` 函数：toplevel None → False（fail-open）；解析失败 → False；resolve 后 relative_to 失败 → True；否则 → False。
4. 改造 `_main_inner` 步骤 7：for 循环前调用 `toplevel = _get_worktree_toplevel()` 一次；循环内首行 `if _is_out_of_repo(fp, toplevel): continue` 短路。
5. 新建 tests/hooks/test_touches_guard_out_of_repo.bats，覆盖 /tmp / /var / ~/ 三类路径 + worktree edge case + NFR p99 延迟骨架（详见 detailed-design §4.2）。
6. 跑 `bats tests/hooks/test_touches_guard_out_of_repo.bats` 全过。
7. 跑 `bats tests/hooks/test_pre_tool_use_guard.bats`（现有用例）确认不退化（V-01/V-03/14 redirect 全过）。

## 验收

- .claude/hooks/touches_guard.py 含 `_get_worktree_toplevel` + `_is_out_of_repo` 两个新函数
- `_main_inner` 步骤 7 在 `_is_in_touches` 之前已先 `_is_out_of_repo` 短路
- touches_guard.py 模块 docstring 含 D-011 双源声明
- bats tests/hooks/test_touches_guard_out_of_repo.bats 全过（/tmp / /var / ~/ + worktree edge case）
- bats tests/hooks/test_pre_tool_use_guard.bats 全过（无退化）
