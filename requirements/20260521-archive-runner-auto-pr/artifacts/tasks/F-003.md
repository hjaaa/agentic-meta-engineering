# F-003 · finalize_requirement 子命令

## 需求描述

新增 `finalize_requirement` 函数 + CLI `--finalize` 子命令（详细设计 §3.1），10 步流程：

1. `_rebind_to_main_repo`
2. `_load_meta`
3. `_precheck_archive_pr_merged`（`--force` 跳过；3 路径全 fail-closed，详细设计 §3.2）
4. 合并问询 `ArchivePrompt(kind="finalize")`（`--yes-finalize` 跳过）
5. `os.chdir(main_repo_root)`（fail-closed）
6. `git pull --ff develop`（fail-closed）
7. `_cleanup_worktree_before_archive`（`--keep-worktree` 跳过）
8. `_delete_local_branch(strict=True)`（`--keep-local-branch` 跳过）
9. `_delete_remote_branch(legacy_resurrect=...)`（`--keep-remote-branch` 跳过）
10. `_render_summary(stage="finalize")`

配套改造：

- `_delete_local_branch` 加 `strict: bool` 参数（AC-A1）
- `_render_summary` 加 `stage: Literal["archive", "finalize"]` 参数（AC-A2）
- 新增 5 个 CLI flag：`--yes-finalize` / `--keep-local-branch` / `--keep-remote-branch` / `--keep-worktree` / `--legacy-resurrect-remote`（最后归 F-007 但 CLI parser 一并加）
- 新增 `_log_finalize_event` 写 `[finalized]` 事件（详细设计 §3.5 C-7 定稿）
- `--force` + `--yes-finalize` 组合警告文案（详细设计 §3.4 C-6 定稿，4 行表）
- ArchiveResult 扩展 `worktree_removed` / `manual_recovery_commands` 字段（outline §5.1）
