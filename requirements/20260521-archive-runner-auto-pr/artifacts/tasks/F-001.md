# F-001 · archive 主流程双阶段化

## 需求描述

改造 `scripts/lib/archive_runner.py::archive_requirement`（来源：scripts/lib/archive_runner.py:733）让阶段 1 仅做 metadata commit + push。具体改造点：

1. `_precheck_dirty` 加 `requirements/<id>/` 前缀白名单（详细设计 §1.1 子项 1-A）
2. `_precheck_phase` 允许 `phase ∈ {testing}` OR `(phase=completed AND archive_pr_number=0)` 重跑入口（详细设计 §1.1 子项 1-B）
3. 新增 `_commit_archive_metadata` 函数（详细设计 §1.2）：含 `ARCHIVE_COMMIT_RE` 正则 idempotent + `context/` 经验类白名单 + `R-ARCHIVE-CONTEXT-DIRTY` fail-closed
4. 新增 `_push_feat_branch` 函数（详细设计 §1.3）：含 `HEAD == origin/<branch>` idempotent + `R-ARCHIVE-PUSH-FAILED` 错误码
5. 删除 `_delete_local_branch` / `_delete_remote_branch` / `_cleanup_worktree_before_archive` 在 `archive_requirement` 中的调用——三件套搬迁到 F-003

## 接口/数据结构

`interfaces_frozen: true`（详细设计 §1.2 + §1.3 已冻结函数签名）：

```python
def _commit_archive_metadata(req_id: str, result: ArchiveResult) -> None: ...
def _push_feat_branch(meta: dict[str, Any], req_id: str, result: ArchiveResult) -> None: ...
```

`ARCHIVE_COMMIT_RE = re.compile(rf"^archive\({re.escape(req_id)}\): metadata$")`。
