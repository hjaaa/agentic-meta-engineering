# F-002 · 自动创建归档 PR

## 需求描述

1. 新增 `_create_archive_pr` 函数（详细设计 §2.1）：调 `gh pr create` 自动开归档 PR
   - `gh pr list` idempotent 三状态处置：OPEN reuse / MERGED abort `R-ARCHIVE-PR-ALREADY-MERGED` / CLOSED abort `R-ARCHIVE-PR-CLOSED`
   - meta.archive_pr_number 冲突校验 → `R-ARCHIVE-PR-NUMBER-MISMATCH`（C-3 决策）
2. 新增 `_write_archive_pr_number` 函数（详细设计 §2.2）：原子写 meta + idempotent 跳重写
3. 新增模板 `.claude/skills/managing-requirement-lifecycle/templates/archive-pr-body.md.tmpl`（C-5 定稿，详细设计 §2.3）：`__REQ_ID__` / `__PR_NUMBER__` / `__BRANCH__` 三占位符
4. 模板渲染由 `str.replace` 三次完成后写临时文件传给 `gh pr create --body-file`（避免引入 jinja2 依赖）

## 接口/数据结构

`interfaces_frozen: true`：

```python
def _create_archive_pr(meta: dict[str, Any], req_id: str, result: ArchiveResult) -> int: ...
def _write_archive_pr_number(req_id: str, meta: dict[str, Any], pr_number: int) -> None: ...
def _render_archive_pr_body(req_id: str, pr_number: int, branch: str) -> str: ...
```

ArchiveResult 扩展（outline §5.1）：`archive_pr_number: int = 0` / `archive_pr_url: str = ""` / `archive_pr_action: Literal["created", "reused", "skipped"]`。
