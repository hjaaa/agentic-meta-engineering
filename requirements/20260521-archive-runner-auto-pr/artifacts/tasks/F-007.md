# F-007 · `--legacy-resurrect-remote` 老需求兜底

## 需求描述

`_delete_remote_branch` 函数加 `legacy_resurrect: bool` 参数（详细设计 §3.3 + §7）：

- `legacy_resurrect=True` 时扩大 already-deleted 判定：任何 stderr 含 `remote ref does not exist` / `not found` / `unknown` → 都视为 already-deleted；不写 error_messages
- `legacy_resurrect=False`（默认）保留现有行为（仅 `remote ref does not exist` 单一识别，来源：scripts/lib/archive_runner.py:607）

CLI parser 加 `--legacy-resurrect-remote` flag（finalize subcommand 专用）。

**适用场景**：历史 REQ（无归档 PR）走 `--finalize --force --legacy-resurrect-remote` 一次性补归档（远程分支可能早被 GitHub auto-delete-head-branch 删除）。

## 接口/数据结构

`interfaces_frozen: true`，修改现有函数签名：
