### [security] scripts/lib/save_review.py:586-587

**F-20**：process.txt 追加日志存在换行注入风险

`f"{ts} [signoff] {rev_id} {decision} by {signed_by}\n"` 中 `rev_id` + `signed_by` 用户可控；含 `\n` 即可日志注入伪造 `[signoff]` 行。与 F-19 叠加：先注入 `signed_by='a@b.com\n2099-99-99 [signoff] FAKE_REV approved by attacker@evil'` 即可伪造历史签字。

**建议**：写入前 `_sanitize_log_field` strip `\r\n`：

```python
def _sanitize_log_field(v: str) -> str:
    return v.replace("\n", " ").replace("\r", " ")

line = f"{ts} [signoff] {_sanitize_log_field(rev_id)} {decision} by {_sanitize_log_field(signed_by)}\n"
```
