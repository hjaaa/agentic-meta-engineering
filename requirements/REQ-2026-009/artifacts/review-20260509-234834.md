## Major 列表（4 keep / 必修）

### F-8 · `read_jsonl_events` 静默吞 JSONDecodeError 无日志
- **File**：`tests/e2e/fixtures/e2e_helpers.py:125-126`
- **来源**：error-handling-checker（critic verdict: not_rebutted）
- **问题**：`except json.JSONDecodeError: pass` 静默吞错，无文件路径无行号。fixture 数据损坏时 6 个测试函数都失去定位线索。
- **建议**：改为 `logger.warning(f"jsonl 第 N 行 JSON 解析失败（path={jsonl_path}, line={stripped!r}）：{exc.msg}")`，至少留下定位线索。

### F-9 · `write_*_jsonl_from_template` JSONDecodeError 把损坏行写入目标
- **File**：`tests/e2e/fixtures/e2e_helpers.py:55-56, 87-88`
- **来源**：error-handling-checker（critic verdict: not_rebutted）
- **问题**：`except json.JSONDecodeError: rewritten.append(line)` 把解析失败的原始行原样 append 进目标 jsonl。fixture loader 应产出干净测试数据，静默保留损坏行让根因被埋。
- **建议**：改为 `raise ValueError(f"fixture 模板含损坏 JSON 行（src={src}, line={stripped!r}）") from exc`，让 fixture 问题在 setup 阶段立即暴露。

### F-11 · `_poll_parent_cancel` OSError 日志缺 parent_jsonl 路径
- **File**：`tests/e2e/fixtures/sub_workflow_mock.py:156-160`
- **来源**：error-handling-checker（critic verdict: not_rebutted）
- **问题**：WARNING 日志只传 `child_run_id` + `exc`，缺 `parent_jsonl` 路径。多并发子 agent 测试场景下，仅凭 child_run_id 无法定位是哪个父 jsonl 不可读。
- **建议**：`logger.warning("MockSubAgent poll 父 jsonl 失败（child_run_id=%s, parent_jsonl=%s）：%s", self.child_run_id, parent_jsonl, exc)`

### F-12 · TC-F8-3 `run_agent` 只 catch RuntimeError
- **File**：`tests/e2e/test_sub_workflow_lifecycle.py:343-344`
- **来源**：error-handling-checker（critic verdict: not_rebutted）
- **问题**：daemon 线程 `except RuntimeError as exc`；若 MockSubAgent 抛其他异常（OSError / ValueError），子线程静默退出，`child_exception` 列表空，断言 `len(child_exception) == 1` 失败时报"子应抛 RuntimeError"，掩盖真实异常类型。
- **建议**：改为 `except Exception as exc:` 并在保存前 `logger.exception(f"TC-F8-3 子线程意外异常类型 {type(exc).__name__}")`。
