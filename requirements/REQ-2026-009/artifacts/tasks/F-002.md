# F-002 · 8 种节点类型实现（含 sub_workflow / loop / approval）

## 需求描述

在 F-001 dispatcher 之上落地 8 种节点类型字段（agent / skill / prompt（含 prompt_file）/ bash / approval / loop / sub_workflow / artifact）的执行决策表 + 字段互斥 + 嵌套深度 ≤ 2 校验。

- 每节点至多 1 类型字段
- `sub_workflow` 透传 args 经 shellQuote 转义注入子 run `$ARGUMENTS`
- `loop` 节点读 jsonl 最近一条 `loop_iteration_completed` 事件填 `$LOOP_OUTPUT` / `$LOOP_PREV_OUTPUT`
- `run_state.py` 新增事件枚举 `cancel_requested` / `parent_cancelled` / `parent_rolled_back`（D-005 / D-010 落地依赖）

来源：detailed-design §1.5（末端 3 节点示例）/ §2.2（frontmatter 字段表）；outline §6（模块视图）；spec §6.4 / §11.2。
