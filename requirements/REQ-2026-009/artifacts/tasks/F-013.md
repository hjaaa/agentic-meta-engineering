# F-013 · requirements/ → runs/ 批量 rename 工具 + pre-commit 拦截规则

## 需求描述

落地批量 rename 工具：`migrate_requirements_to_runs(dry_run, include_history_comments, whitelist) → MigrationReport`（含 `references_found` / `risky_unmapped` / `skipped_whitelist` / `moved_directories` 等 dataclass）。

**6 层扫描矩阵**：

- 代码层（grep + AST）
- 配置层（frontmatter 解析）
- gate 层（registry.yaml）
- 文档层（CLAUDE.md / engineering-spec/**）
- 历史层（白名单跳过历史 ADR）
- git 层（不改 commit message）

**kind 分类**：literal / yaml_glob 自动改 / f_string / concat 进 `risky_unmapped` 人工 review。

**pre-commit hook** 拦截新增 `'requirements/REQ-'` 字面量 → exit 2 + 提示改用 `'runs/REQ-'`；命中白名单或 markdown 引用块/代码块放行；`CLAUDE_GATES_GLOBAL_BYPASS` reason ≥ 8 字符可绕过。

前置：F-011 自举验证通过 + migration 测试 21/21 pass。

来源：detailed-design §9 全章 / D-002 / outline §1.2（~80 行）。
