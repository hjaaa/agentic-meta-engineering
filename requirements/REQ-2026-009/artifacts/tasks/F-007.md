# F-007 · workflow_rollback.py + 跨父子归档 + 双层锁中断保护

## 需求描述

落地 `rollback_run(run_id, to_node, target_id=None) → RollbackResult`：

- mv 语义 = `shutil.move` 产物到 `.archived/<ts>/`
- 父跨 sub_workflow 节点时整目录 mv 子 run 到 `sub_runs/<child-id>/`
- 多次 rollback 独立 timestamp 目录并存
- jsonl 尾部 mv 为 `.tail`
- 双层锁选型：`fcntl.flock`（advisory）+ `os.O_EXCL`（原子 `.in_progress` 标记）解决并发互斥 + 崩溃中间状态识别
- 续跑流程：扫 `.in_progress` 残留 → 拿锁完成剩余 mv → 删标记 + `RollbackResult.partial=True`
- F-008 e2e 测试 §7.2 复用本 feature 的 F1 实现

来源：detailed-design §6 全章 / D-010。
