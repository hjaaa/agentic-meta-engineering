# F-008 · sub_workflow 父子状态联动 e2e（D-005 cancel + parent_cancelled）

## 需求描述

落地 sub_workflow 父子状态联动 e2e 测试：

- 父用 `Agent({run_in_background: true})` 派子
- 用户 cancel → 父 jsonl 写 `cancel_requested` → 子 subagent 在每节点边界 poll 父 jsonl → 检测命中即写 `parent_cancelled` 到子 jsonl + graceful 退出
- 父等子 graceful 返回或 30s 超时调 `TaskStop({task_id})` forceful 兜底
- 主要交付：MockSubAgent 类（poll_interval_ms 可调）+ §7.4 单测矩阵 6 用例（2 主 + 4 边界）+ 复用 F-007 F1 fixture
- 子 jsonl 永远由子自身写，无跨 run 文件写权限——绕开 TaskStop graceful 不明确 + 跨 subagent 写权限两个不确定性

来源：detailed-design §7 全章 / D-005。

## 接口/数据结构

详见 `requirements/REQ-2026-009/artifacts/detailed-design.md` §7.1（cancel graceful Mermaid 时序图）/ §7.2（rollback 跨父子复用 §6 F1）/ §7.3（mock 优先决策 + MockSubAgent 雏形）/ §7.4（6 用例矩阵）。
