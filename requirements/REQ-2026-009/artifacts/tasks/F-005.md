# F-005 · 9 个 /workflow:* 通用命令 + managing-workflow-runs 伞形 Skill

## 需求描述

落地 9 个 `/workflow:*` 通用命令：`run` / `continue` / `save` / `status` / `list` / `approve` / `reject` / `rollback` / `cancel`（`submit` / `archive` 已下沉为 yaml 节点见 F-003 §1.5）+ `managing-workflow-runs` 伞形 Skill 派发 9 子动作。

- 每命令 SKILL.md 子动作开头先做 §1.3 状态机矩阵校验（行=run state / 列=命令；✗ 直接 exit 1 + 错误文案）
- 命令实现细分到 `reference/category-rules/*.md` + `command-implementations/<cmd>.md` 两层结构（参考 managing-requirement-lifecycle）

来源：detailed-design §1.1-§1.4 / outline §1.2（~800 行）。
