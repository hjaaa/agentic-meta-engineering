## 需求描述

新建 `requirements/ci.txt`（5 行内容：pyyaml / ruamel.yaml / pathspec>=0.12,<1.0 / ruff / pytest，仅 pathspec 保留版本范围）。改 workflow yml 的 `Install dependencies` step 为 `pip install -r requirements/ci.txt`。改 onboarding md 把单条 `pip install pyyaml` 替换为同样 `-r requirements/ci.txt` + 附 brew / apt-get 安装 bats / hyperfine 说明。非 Python 工具不进 ci.txt。

## 触及范围

- `requirements/ci.txt`（新建）
- `.github/workflows/quality-check.yml`（行 33-34 区域）
- `context/team/onboarding/learning-path/01-environment.md`（行 25 区域）

## 实施步骤

1. 写 `requirements/ci.txt`（内容见 detailed-design.md §2.1）。
2. 改 workflow yml line 34（`pip install ... ruff pytest` → `pip install -r requirements/ci.txt`）。
3. 改 onboarding md line 25（单条 pyyaml → `-r requirements/ci.txt` + 系统级工具说明）。
4. 本地 clean venv 验证 `pip install -r requirements/ci.txt && pytest tests/ --ignore=tests/benchmarks/` 退码 0。
5. 推 PR；workflow 必须复跑通过。

## 验收

- requirements/ci.txt 5 行与 workflow 现 pip install 字面量对齐

- onboarding md 不再含独立的 `pip install pyyaml` 字面量
- 本地 clean venv 后 `pip install -r requirements/ci.txt` 退码 0
