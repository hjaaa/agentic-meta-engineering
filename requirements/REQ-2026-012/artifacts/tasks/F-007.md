## 需求描述

Makefile 末尾追加 `ci-local` 聚合 target + 8 个子 target（ci-local-deps / -gates / -pytest / -settings-check / -bats / -ruff / -render-check / -routing-e2e），按 workflow step 顺序串行依赖；每个子 target 失败时 stderr 末段写 `FAIL: <label>`（AC-5 自动断言契约）；Makefile 顶部加 FAIL labels 注释表。hyperfine 默认嵌在 ci-local-bats 内由 V-06 触发，不单独立 target；benchmarks 由 pytest --ignore 跳过。同时新建 `context/team/experience/test-assets-must-be-wired-into-ci.md` 并挂入 `context/team/experience/INDEX.md`。依赖 F-003。

## 触及范围

- `Makefile`（末尾追加）
- `context/team/experience/test-assets-must-be-wired-into-ci.md`（新建）
- `context/team/experience/INDEX.md`（追加一行索引）

## 实施步骤

1. 把 detailed-design.md §2.3 的 Makefile 完整内容（行约 75-150 区域）逐字复制追加到 `Makefile` 末尾。
2. 创建 `context/team/experience/test-assets-must-be-wired-into-ci.md`，完整内容逐字复制自 detailed-design.md §2.9（行约 205-239），注意嵌套 markdown 代码块边界，复制时把外层 ``` ``` 去掉。
3. 在 `context/team/experience/INDEX.md` 加一行：`- [测试资产必须接入 CI 执行入口](test-assets-must-be-wired-into-ci.md) — 新增 shell/e2e/contract 测试默认进 CI；不进 CI 必须说明原因 + 手跑命令`。
4. 本地 clean checkout 跑 `make ci-local`：必须退码 0。
5. AC-5 失败注入断言（与 detailed-design.md §3 AC-5 第二段 1:1）：
   ```bash
   # 直接强制让一个子 target 退非 0：
   make ci-local-deps && false 2>&1 | grep -E '^FAIL: ci-local-deps'
   ```
   该命令必须 grep 命中。注：不需要真的 mv ci.txt——`&& false` 即可在子 target exit 0 后强制 shell 退非 0；如果子 target 本身失败，`||` 分支已发 `FAIL: ci-local-deps` 到 stderr，grep 同样命中。
6. CI `check-index.sh` 不报缺索引。

## 验收

- clean checkout 后 `make ci-local` 退码 0（含 hyperfine 路径，跳过 tests/benchmarks/）

- Makefile 顶部 FAIL labels 注释表 8 行与子 target 名 1:1
- `context/team/experience/test-assets-must-be-wired-into-ci.md` 存在且 INDEX.md 含对应一行
- check-index.sh 不报缺索引
