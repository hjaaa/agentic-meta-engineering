## 需求描述

新建 scripts/lib/worktree_manager.py：7 个函数 + 2 个 dataclass（标准库 only，subprocess + pathlib）。dataclass：WorktreeState（is_git_repo / is_linked_worktree / is_submodule / is_detached / branch / worktree_path / git_dir / git_common_dir）；WorktreeInfo（path / branch / base_branch / owner∈{workflow, external, none} / created）。函数：detect_worktree_state(repo_root)→git rev-parse --git-dir 与 --git-common-dir 双源判定，path 不含 modules/ 判 linked worktree；select_worktree_location(repo_root, branch, preference)→按优先级选 .worktrees/feat-req-<key>；ensure_worktree_dir_ignored(repo_root, location)→.gitignore 校验 fail-closed（缺则 BootstrapError）；create_worktree(repo_root, branch, base_branch, location)→git worktree add，rc!=0 抛 BootstrapError；run_worktree_setup(worktree_path, policy)→subprocess 调 make gates-validate 解析 exit code，必要时透传 CLAUDE_GATES_AUDIT_ROOT；resolve_main_repo_root(worktree_path)→worktree 找主仓根；cleanup_worktree_if_owned(meta, repo_root)→三重保护（owner=workflow + 路径 startswith(.worktrees/feat-req-) 白名单 + cwd ≡ main_repo_root）；新增集成测试 tests/integration/test_worktree_protect_branch.bats 验证 worktree 内 hook 不误触发 protect-branch。落地 outline-design §流程二/三/四 + spec §5.1 + tech-feasibility §1.2 + §待澄清 #1。
