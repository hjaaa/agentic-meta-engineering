## 需求描述

改 scripts/lib/workflow_run.py：(1) _generate_req_id 函数体替换为调用 requirement_naming.generate_requirement_key（保留函数名作为兼容入口，但内部不再 mkdir-as-lock，改为扫 _scan_existing_requirement_keys 注入 existing_keys 集合；P1-2 修复：避免主仓 requirements/<key>/ 占名污染）；(2) _parse_args 扩展三个新参数 --slug / --no-worktree / --worktree-policy，**支持 --key value 空格 与 --key=value 等号 两种 long-option 形式**（P2 修复：与 spec §5.4 L380 示例一致）；(3) 中文标题 + 缺 --slug 时 fail-closed exit 1，stderr 提示 '中文标题需显式 --slug <ascii-slug>' 与 D-013 链接；(4) _run_requirement 内置 bootstrap retry 循环：捕获 BootstrapError(reason='path_or_branch_exists') 后 bump existing_keys 重试，仅此 reason 重试，其它失败直接传播；上限 -99 后抛 SlugError；(5) legacy REQ-YYYY-NNN 路径在 --slug 缺失且 title 仅 ASCII 时通过 generate_requirement_key 与 _generate_req_id 共存（短期过渡）。落地 outline-design §模块划分既有改造点 + tech-feasibility §1.3 + spec §11 Phase 2。
