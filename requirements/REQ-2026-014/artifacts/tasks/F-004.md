## 需求描述

改 scripts/lib/workflow_bootstrap.py：(1) _checkout_feature_branch 拆为 _setup_worktree_or_branch：先 detect_worktree_state，若已在 linked worktree 内则 bind current（D-004 复用），否则 ensure_worktree_dir_ignored → create_worktree → run_worktree_setup；(2) _bootstrap_requirement 写文件顺序改为 worktree-first：步骤 1（解析 key / slug） → 步骤 2（建 worktree） → 步骤 3（worktree 路径下 mkdir artifacts/）→ 步骤 4-6（render meta.yaml / plan.md / process.txt 落 worktree）→ 步骤 7（写 run-state.jsonl）→ 步骤 8（baseline 通过输出成功）；(3) _bootstrap_rollback 顺序补 worktree remove 前置：步骤 0 cd main_repo_root → 步骤 1 git worktree remove <path> + git worktree prune → 步骤 2 git branch -D → 步骤 3 rmtree requirements/<key>（主仓根 + worktree path 双扫）；(4) 显式传 active_repo_root（worktree path）给 _write_bootstrap_artifacts，避免 R1 路径错乱。落地 outline-design §流程一 + spec §6 + tech-feasibility §1.3 + R1 缓解。
