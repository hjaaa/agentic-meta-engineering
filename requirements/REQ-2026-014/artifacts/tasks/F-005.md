## 需求描述

改 scripts/lib/archive_runner.py：(1) archive_requirement 函数 5 项预检通过后、_atomic_write_meta 之前注入 cleanup 入口三步（P1-3）：先 worktree_manager.resolve_main_repo_root(Path.cwd()) → os.chdir(main_root) → worktree_manager.cleanup_worktree_if_owned(meta, main_root)；不再使用 REPO_ROOT 推断主仓根（archive 命令可能从 worktree 内运行，REPO_ROOT 会被误解析为 worktree 根，导致 self-remove）；(2) owner=workflow 路径正常清理；(3) owner=external 输出 INFO 日志 'worktree cleanup skipped: external'，不调 git worktree remove；(4) meta.yaml 缺 worktree 字段时降级为 enabled=false 兼容 legacy（防御性 meta.get('worktree', {})）；(5) archive.md 接口契约 frozen，仅追加内部步骤不改 CLI 入参 / 退出码。落地 outline-design §流程四 archive cleanup 三重保护 + spec §11 Phase 3 + tech-feasibility §1.5 + R5/R7 缓解。
