## 需求描述

新建 scripts/lib/requirement_naming.py：6 个纯函数（标准库 only，无第三方依赖）。函数清单：normalize_slug(raw)→ASCII slug 规范化（lower / 连字符 / 字符集校验）；derive_slug_from_title(title)→仅 ASCII 标题派生，中文标题返回 None（fail-closed by --slug 逃生）；generate_requirement_key(date, slug, requirements_root)→新格式 YYYYMMDD-<slug>，同日同 slug 第二个落 -02 后缀（原子 mkdir(exist_ok=False) + 重试，与 _generate_req_id 一致语义）；is_legacy_requirement_key(key)→识别 ^REQ-\d{4}-\d{3}$ 旧格式（复用 _REQ_ID_PATTERN 正则）；branch_for_requirement_key(key)→统一 feat/req-<key>（新旧两种 key 都接受）；directory_for_requirement_key(key)→requirements/<key> 路径。落地 outline-design §模块划分 / spec §5.1 表。
