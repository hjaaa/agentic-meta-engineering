## 需求描述

新建 scripts/lib/requirement_naming.py：6 个纯函数（标准库 only，无第三方依赖；**纯字符串处理，不调任何 IO / mkdir / listdir**——P1-2 修复）。函数清单：normalize_slug(raw)→ASCII slug 规范化（lower / 连字符 / 字符集校验）；derive_slug_from_title(title)→仅 ASCII 标题派生，中文标题返回 None（fail-closed by --slug 逃生）；generate_requirement_key(date, slug, *, existing_keys=())→新格式 YYYYMMDD-<slug>，候选 key 在 existing_keys 中存在时递增后缀 -02 / -03 / ... 至 -99 后抛 SlugError（来源：context/team/engineering-spec/specs/2026-05-17-worktree-isolation-migration-design.md:416）；is_legacy_requirement_key(key)→识别 ^REQ-\d{4}-\d{3}$ 旧格式（复用 _REQ_ID_PATTERN 正则）；branch_for_requirement_key(key)→统一 feat/req-<key>（新旧两种 key 都接受）；directory_for_requirement_key(key)→requirements/<key> 路径。并发兜底由 F-004 _run_requirement / _setup_worktree_or_branch 的 git worktree add retry 循环承担（仅 stderr 'already exists' 触发，其它错误不重试）。落地 outline-design §模块划分 / spec §5.1 表。
