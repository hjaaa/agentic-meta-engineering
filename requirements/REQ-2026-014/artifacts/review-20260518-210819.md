### F-13 [major → suggestion] · except Exception 范围过宽

- **文件**：`scripts/lib/archive_runner.py:631`
- **问题**：`_cleanup_worktree_before_archive` 对 `resolve_main_repo_root` 失败 catch `except Exception`；该函数已规约只抛 `WorktreeBootstrapError`（worktree_manager.py:616 `raise BootstrapError(...)`），catch-all 会掩盖意外异常类型
- **修法**：
  ```python
  from worktree_manager import WorktreeBootstrapError  # 或 BootstrapError
  ...
  try:
      main_repo_root = worktree_manager.resolve_main_repo_root(Path.cwd())
  except WorktreeBootstrapError as exc:
      logger.error("worktree cleanup skipped: resolve_main_repo_root failed req_id=%s: %s", req_id, exc.reason)
      return
  ```

### F-14 [minor / suggestion] · os.chdir 无 try/except

- **文件**：`scripts/lib/archive_runner.py:639`
- **问题**：`os.chdir(main_repo_root)` 裸调；resolve 成功保证 main_repo_root 存在，但权限 / race 仍可能抛 `OSError` → archive 主流程 crash，违反 D-009 fail-soft 语义
- **修法**：
  ```python
  try:
      os.chdir(main_repo_root)
  except OSError as exc:
      logger.error("worktree cleanup skipped: chdir to %s failed req_id=%s: %s", main_repo_root, req_id, exc)
      return
  ```
